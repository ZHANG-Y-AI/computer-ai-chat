# 编程知识点答疑、代码调试与学习困惑

## 一、概念类：面向对象三大特性是什么？

- **封装**：把数据与操作数据的方法绑在对象内，对外隐藏内部实现细节，通过公开接口交互。
- **继承**：子类复用父类的属性与方法，并可重写或扩展；注意「组合优于继承」在许多场景更灵活。
- **多态**：同一接口或父类引用，在运行期指向不同子类实现，调用同一方法名产生不同行为。

## 二、概念类：同步与异步、阻塞与非阻塞

- **同步**：调用方等待被调用方完成后再继续。
- **异步**：调用发起后立即返回，结果通过回调、Promise、Future、事件或消息稍后送达。
- **阻塞**：当前线程在等待 I/O 或锁时不做其他事；**非阻塞**常配合轮询或多路复用，在单线程里调度多个 I/O。实际开发中常组合使用（如 async/await 语法糖建立在异步模型之上）。

## 三、调试：通用流程（各语言适用）

1. **复现**：固定输入、版本、操作系统；能稳定复现才容易修。
2. **缩小范围**：二分注释、最小示例（Minimal Reproducible Example）。
3. **读报错**：编译错误看首条；运行异常看栈顶与 Caused by；前端看控制台 Network 与 Console。
4. **打日志/断点**：在数据流关键节点打印「输入—中间状态—输出」。
5. **验证修复**：补一条会失败的用例再修到通过，防止回归。

## 四、常见错误类型与直觉判断

| 现象 | 可能原因 | 建议动作 |
|------|----------|----------|
| NullPointer / 空引用 | 未判空即使用 | 在调用链上找第一个可能为 null 的来源 |
| 数组越界 | 循环边界或空列表 | 检查 `length-1` 与 `<=` 误用 |
| 死锁 | 多锁顺序不一致 | 统一加锁顺序或缩小锁粒度 |
| 接口 404 | 路径、方法、网关前缀错误 | 对照路由表与反向代理配置 |
| 401/403 | Token 失效或权限不足 | 看鉴权头、角色与接口注解 |
| CORS 报错 | 浏览器跨域策略 | 开发环境代理或后端允许源配置 |
| 依赖冲突 | 版本不兼容 | 锁定版本、查看依赖树 |

## 五、学习困惑：「算法要刷到什么程度？」

- **基础**：复杂度分析、排序查找、双指针、哈希、栈队列、二叉树遍历、图 BFS/DFS。
- **进阶**：动态规划常见模型、并查集、最短路与拓扑排序（按岗位选择性深入）。
- **与项目结合**：在业务里找「可抽象为经典模型」的子问题，比纯刷题更记得牢。

## 六、学习困惑：「英语不好能学编程吗？」

能。关键字数量有限；重要的是**读官方文档的习惯**与**用翻译工具辅助**。建议逐步积累高频词（request、response、deprecated、breaking change）。

## 七、学习困惑：「数学不好能否做开发？」**

大部分业务开发与 Web 开发对数学要求适中；**图形学、机器学习、量化**等方向对线性代数与概率要求更高。可按目标岗位调整数学投入。

## 八、与 AI 对话时的提问技巧（便于得到清晰解答）

- 提供：**语言与版本**、**完整报错文本**、**相关代码片段**、**已尝试的步骤**。
- 明确期望：要「思路」还是「可运行示例」、是否约束第三方库。
- 对回答要求：请指出**可能的风险点**（线程安全、注入、性能），便于自己二次判断。
