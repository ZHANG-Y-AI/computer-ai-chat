# 前端与脚本语言学习路线（入门到进阶）

## 一、HTML / CSS（Web 呈现基础）

### 入门
- HTML5 语义标签（header、nav、main、article）、表单与常用属性。
- CSS 选择器、盒模型、Flex 布局、Grid 入门、响应式（媒体查询）。

### 进阶
- 可访问性（a11y）基础：焦点管理、对比度、aria 属性。
- 预处理器或原子化方案（Sass / Tailwind 二选一深入即可）。
- 性能基础：关键 CSS、图片懒加载、减少重排重绘。

## 二、JavaScript（语言核心）

### 入门
- 变量与作用域（let/const）、数据类型、运算符、控制流。
- 函数、箭头函数、解构、模板字符串、模块 import/export。
- 数组与对象常用方法（map/filter/reduce）、JSON 处理。
- 异步基础：Promise、async/await、fetch。

### 进阶
- 事件循环、宏任务与微任务、闭包与内存泄漏防范。
- ES Modules 与构建工具概念（Vite / Webpack 了解其一）。
- TypeScript 入门：类型注解、接口、泛型基础，在中小型项目中渐进采用。

### 实战方向
- **前端框架**：Vue 3（组合式 API）或 React（Hooks）二选一为主力，理解组件、状态、路由。
- **Node.js 基础**：文件系统、简单 HTTP 服务、环境变量，为全栈或工具脚本打基础。

## 三、TypeScript（可选但强烈建议）

### 入门
- 在 JS 项目上开启严格模式逐步加类型；为函数参数与返回值写类型。
- 联合类型、字面量类型、可选链与空值合并。

### 进阶
- 泛型约束、工具类型（Partial、Pick、Omit）、声明合并与模块解析。
- 与框架结合：Vue/React 官方推荐的 TS 模板与类型推导习惯。

## 四、Shell / 自动化（提升工程效率）

### Bash 入门
- 管道与重定向、变量、条件判断、循环、简单函数。
- 与 Git、curl、grep、sed、awk 组合完成日常运维与数据处理。

### 进阶
- 编写可维护脚本：参数校验、退出码、日志；在 CI 中调用脚本完成构建与检查。

## 五、学习顺序建议（前端方向）

HTML/CSS → JavaScript 核心 → 一个主流框架 → TypeScript → 工程化（Vite、ESLint、测试）→ 性能与网络（浏览器缓存、HTTP2、安全基础）。
