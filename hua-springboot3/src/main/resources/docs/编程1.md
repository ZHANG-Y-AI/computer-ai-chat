# 编程学习路线指南

## 一、Python 学习路线

### 1. 入门阶段
- 安装 Python 环境（推荐 Python 3.10+）
- 掌握基础语法：变量、数据类型、运算符
- 学习控制流：if/else、for/while 循环
- 函数定义与调用、参数传递
- 常用数据结构：列表、字典、元组、集合

### 2. 进阶阶段
- 面向对象编程（OOP）：类、继承、封装、多态
- 文件操作与异常处理
- 模块与包管理（pip）
- 常用标准库：os、sys、datetime、json
- 虚拟环境管理：venv / conda

### 3. 实战方向
- **Web 开发**：Flask / Django 框架
- **数据分析**：NumPy、Pandas、Matplotlib
- **爬虫开发**：requests、BeautifulSoup、Scrapy
- **自动化脚本**：selenium、pyautogui
- **机器学习**：scikit-learn、TensorFlow、PyTorch

### 4. 推荐资源
- 官方文档：https://docs.python.org/zh-cn/3/
- 书籍：《Python 编程：从入门到实践》
- 练习平台：LeetCode、牛客网

## 二、Java 学习路线

### 1. 入门阶段
- JDK 安装与环境配置
- 基础语法：数据类型、变量、运算符
- 控制语句：if、switch、for、while
- 数组与字符串操作
- 方法定义、重载与递归

### 2. 进阶阶段
- 面向对象：类与对象、继承、多态、接口、抽象类
- 异常处理：try/catch/finally
- 集合框架：ArrayList、HashMap、LinkedList
- 泛型、枚举、注解
- IO 流与文件操作
- 多线程与并发基础

### 3. 高级阶段
- JVM 原理：内存模型、垃圾回收
- 设计模式（单例、工厂、策略等）
- 反射与动态代理
- 数据库连接：JDBC、MyBatis

### 4. 实战方向
- **后端开发**：Spring Boot / Spring Cloud 微服务
- **Android 开发**：Android SDK
- **大数据**：Hadoop、Spark（Java API）

### 5. 推荐资源
- 官方文档：https://docs.oracle.com/javase/
- 书籍：《Java 核心技术》、《Effective Java》
- 视频：B站搜索「尚硅谷 Java」

## 三、C/C++ 学习路线

### 1. C 语言入门
- 编译环境：GCC / MinGW / VS Code
- 基础语法：数据类型、运算符、控制流
- 函数与作用域
- 数组与字符串
- 指针（重点难点）
- 结构体与共用体
- 文件操作

### 2. C++ 进阶
- C++ 对 C 的扩展：引用、内联函数
- 面向对象：类、构造/析构函数、继承、多态
- 运算符重载
- 模板（函数模板、类模板）
- STL 标准模板库：vector、map、set、algorithm
- 异常处理
- 智能指针（C++11）

### 3. 实战方向
- **系统编程**：操作系统、驱动开发
- **游戏开发**：Unreal Engine（C++）
- **嵌入式开发**：单片机、RTOS
- **竞赛算法**：ACM/OI 编程竞赛

### 4. 推荐资源
- 书籍：《C Primer Plus》、《C++ Primer》
- 练习平台：洛谷、Codeforces
