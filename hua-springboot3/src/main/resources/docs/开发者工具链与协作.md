# 开发者工具链与协作（贯穿各语言）

## 一、Git 版本控制

### 入门命令
- `git init`、`clone`、`status`、`add`、`commit`、`push`、`pull`。
- 分支：`branch`、`checkout` 或 `switch`、`merge`；理解 fast-forward 与冲突解决。

### 进阶
- `rebase` 与交互式整理提交历史（注意协作规范，避免强推公共分支）。
- `.gitignore` 与 LFS 大文件；tag 与 release 工作流。
- Code Review：小 PR、清晰描述、关联 issue。

## 二、Docker 与运行环境一致性

### 入门
- Dockerfile：FROM、WORKDIR、COPY、RUN、EXPOSE、CMD。
- `docker build` 与 `docker run`，卷挂载用于开发热更新。

### 进阶
- docker-compose 编排多容器（应用 + 数据库 + 缓存）；健康检查与资源限制概念。

## 三、HTTP 接口调试

- 浏览器开发者工具 Network 面板；Postman / Insomnia / curl。
- 理解 Header：Authorization、Content-Type；常见 Body：JSON、form-urlencoded、multipart。

## 四、正则表达式（跨语言通用思想）

- 字符类、量词、分组与捕获、非贪婪匹配；在日志检索与数据校验中高频使用。
- 各语言 API 不同，但模式语法高度相似；复杂规则优先可读性，避免过度一行化。

## 五、文档与沟通

- README：项目简介、环境要求、启动步骤、目录结构、许可证。
- CHANGELOG：面向用户的版本变更说明；ADR（架构决策记录）可选用于团队项目。

## 六、安全与质量底线（所有方向都应了解）

- 不把密钥提交到仓库；使用环境变量或密钥管理服务。
- 对用户输入做校验与转义，防范 SQL 注入与 XSS。
- 依赖漏洞扫描（语言生态自带或第三方工具），定期升级补丁版本。
