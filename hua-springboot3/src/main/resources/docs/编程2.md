# 计算机基础知识手册

## 一、数据结构与算法

### 1. 常见数据结构
| 数据结构 | 特点 | 常见操作时间复杂度 |
|--------|------|------------------|
| 数组 | 连续内存，随机访问快 | 查找 O(1)，插入 O(n) |
| 链表 | 非连续内存，插入删除快 | 查找 O(n)，插入 O(1) |
| 栈 | 后进先出（LIFO） | 入栈/出栈 O(1) |
| 队列 | 先进先出（FIFO） | 入队/出队 O(1) |
| 哈希表 | 键值对，快速查找 | 查找/插入 O(1) 平均 |
| 二叉树 | 层次结构，便于搜索 | 查找 O(log n) 平均 |
| 堆 | 完全二叉树，优先队列 | 插入/删除 O(log n) |
| 图 | 顶点与边，复杂关系 | DFS/BFS O(V+E) |

### 2. 常见算法
- **排序算法**：冒泡、选择、插入、归并、快速排序
- **搜索算法**：二分查找、深度优先搜索（DFS）、广度优先搜索（BFS）
- **动态规划**：背包问题、最长公共子序列、最短路径
- **贪心算法**：活动选择、最小生成树
- **分治算法**：归并排序、快速排序、大整数乘法

### 3. 算法复杂度
- 时间复杂度：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
- 空间复杂度：衡量算法占用内存空间的大小

## 二、数据库基础

### 1. SQL 基础
```sql
-- 查询
SELECT * FROM users WHERE age > 18 ORDER BY name;

-- 插入
INSERT INTO users (name, age) VALUES ('张三', 20);

-- 更新
UPDATE users SET age = 21 WHERE name = '张三';

-- 删除
DELETE FROM users WHERE id = 1;

-- 联表查询
SELECT u.name, o.order_no
FROM users u
INNER JOIN orders o ON u.id = o.user_id;
```

### 2. 数据库设计原则
- **三范式（3NF）**：消除数据冗余，保证数据一致性
- **索引优化**：为常用查询字段建立索引，提升查询速度
- **事务（ACID）**：原子性、一致性、隔离性、持久性

### 3. 常见数据库
- **关系型**：MySQL、PostgreSQL、Oracle、SQL Server
- **非关系型**：Redis（缓存）、MongoDB（文档）、Elasticsearch（搜索）

## 三、操作系统基础

### 1. 核心概念
- **进程 vs 线程**：进程是资源分配单位，线程是 CPU 调度单位
- **内存管理**：虚拟内存、分页、分段
- **文件系统**：FAT32、NTFS、ext4
- **I/O 模型**：阻塞 I/O、非阻塞 I/O、多路复用、异步 I/O

### 2. 常用 Linux 命令
```bash
# 文件操作
ls -la          # 列出文件
cd /home        # 切换目录
cp src dst      # 复制文件
mv src dst      # 移动/重命名
rm -rf dir      # 删除目录

# 进程管理
ps aux          # 查看进程
kill -9 PID     # 强制终止进程
top             # 实时进程监控

# 网络
ping host       # 网络连通测试
netstat -tulnp  # 查看端口占用
curl url        # HTTP 请求
```

## 四、计算机网络基础

### 1. OSI 七层模型
| 层级 | 名称 | 作用 | 典型协议 |
|-----|------|------|--------|
| 7 | 应用层 | 用户接口 | HTTP、FTP、SMTP |
| 6 | 表示层 | 数据格式转换 | SSL/TLS |
| 5 | 会话层 | 会话管理 | — |
| 4 | 传输层 | 端到端传输 | TCP、UDP |
| 3 | 网络层 | 路由寻址 | IP、ICMP |
| 2 | 数据链路层 | 帧传输 | Ethernet、WiFi |
| 1 | 物理层 | 物理信号传输 | 网线、光纤 |

### 2. HTTP 常见状态码
- **2xx 成功**：200 OK、201 Created、204 No Content
- **3xx 重定向**：301 永久重定向、302 临时重定向
- **4xx 客户端错误**：400 Bad Request、401 未授权、403 禁止、404 Not Found
- **5xx 服务端错误**：500 内部错误、502 Bad Gateway、503 Service Unavailable

### 3. TCP vs UDP
| 特性 | TCP | UDP |
|-----|-----|-----|
| 连接方式 | 面向连接（三次握手） | 无连接 |
| 可靠性 | 可靠，有确认机制 | 不可靠 |
| 速度 | 较慢 | 较快 |
| 应用场景 | HTTP、文件传输 | 视频流、游戏、DNS |
